# 🚀 WorkNest – SaaS Landing Page

A modern, high-converting SaaS landing page built using **React**, **Tailwind CSS**, and **Framer Motion**.

This project focuses on clean UI/UX, smooth animations, and real-world SaaS design patterns.

---

## 🌐 Live Demo
👉 https://work-nest-eta.vercel.app/

---

## 📌 Features

- ⚡ Fully responsive design (mobile, tablet, desktop)
- 🎨 Modern dark UI with gradient accents
- 🎬 Smooth animations using Framer Motion
- 🧠 Conversion-focused layout
- 📊 Product dashboard preview section
- 💰 Pricing section with tiers
- 💬 Testimonials section
- ❓ FAQ with accordion functionality
- 🚀 Final CTA (Call-To-Action) section

---

## 🛠️ Tech Stack

- **Frontend:** React (Vite)
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
